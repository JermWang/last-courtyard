# Game demos

Each demo has its own folder for its design, source project, and playable export as it develops.

| Demo | Status | Core idea |
| --- | --- | --- |
| [Downhill Bike](downhill-bike/README.md) · [Play](https://jermwang.github.io/last-courtyard/downhill-bike/) | Playable | Descend a 2.64 km mountain with rock ridges, bowls, optional jumps and multiple ways down. |
| [Night Shift](night-shift/README.md) | Concept | Sneak through a warehouse, steal one object, and escape after the guards notice. |
| [Ricochet Workshop](ricochet-workshop/README.md) | Concept | Bank shots around cover, choose one upgrade, and survive the final wave. |

The Last Courtyard is the existing project at the workspace root.

GitHub Pages hosts solo play. Downhill crew races require the Node/WebSocket server included with the demo; GitHub Pages cannot run that server.
